# ATI — v0.2 Data Source Target

Existing source normalization/extraction semantics remain valid unless explicitly migrated by PR 28. An Evidence-producing semantic format must define an approved stable upstream source identity before it can publish global Evidence; retrieval time or a random consumer-side UUID is not a substitute. Reference-corpus sources remain distinct from Evidence-producing sources.

`DATA_SOURCES.md` remains the delivered source contract and must be reconciled source-by-source as producer migration lands.
